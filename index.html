Sobre mim

Um pouco da pessoa por trás do código.

Olá! Sou João Henrique, estudante do 2º B do Técnico em TI e apaixonado por desenvolvimento back-end. Gosto de entender como as coisas funcionam por baixo dos panos — das requisições HTTP à modelagem de um banco de dados.

Minha rotina é dividida entre a sala de aula, projetos pessoais e muita prática: escrever código, quebrar a cabeça com um bug, refatorar e aprender algo novo no processo. Acredito que boa tecnologia é invisível para o usuário e impecável nos bastidores.

Meu objetivo é evoluir como desenvolvedor, colaborar em projetos reais e construir sistemas rápidos, seguros e bem estruturados.

  • Lógica de programação e estruturas de dados
  • APIs REST e integração com bancos de dados
  • Versionamento com Git e GitHub
  • Interfaces limpas com HTML, CSS e JavaScript puro
